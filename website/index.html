Why “bitácora”?

In Spanish, bitácora is the binnacle — the stand beside the helm that holds the ship’s compass. It is also where the captain kept the logbook: course, weather, people aboard, what happened and when. One entry per watch, written plainly so anyone could read it years later.

That is the idea behind the app. A daily journal at the top, an outline under it, and plain Markdown files underneath everything — a record that belongs to you and outlasts any tool.

Features

Everything the log needs, nothing that gets in the way.

Journals and outlines

A page for every day, blocks you can fold, zoom into and reference. Code fences, quotes and NOTE/TIP/WARNING callouts render like Logseq does.

Instant search

Its own SQLite + FTS5 index answers searches, backlinks and queries as you type, even on graphs with thousands of pages.

Tasks view

Every open task grouped Overdue, This week, Later and No date. Filter by marker, priority or page; pick a new date from a calendar.

Graph view

A force layout of your pages with focus on N hops. Settings live in config.edn; export to SVG or PNG.

Context at hand

The right panel shows the local graph, page properties, backlinks with snippets and the blocks you opened with Shift+click.

Git sync, built in

Automatic commit, pull and push. Metadata conflicts resolve themselves; content conflicts are shown block by block — never as markers in your notes.

Keyboard first

Command palette on Ctrl/⌘K, TODO/DOING/DONE on 1·2·3, keymaps grouped by context and tabs for everything.

Light and dark, same voice

Bitácora Light and Dark come from one set of design tokens. Fonts are embedded, so text looks the same on every system.

Native and fast

Rust and GPUI render the whole window on the GPU. A frameless window, its own top bar, and it reopens your last graph at startup.

Logseq compatible

Open your graph. Change nothing.

Bitácora reads and writes the same Logseq 0.10 Markdown graph, with the same paths, file names and format. You can keep Logseq on the same folder and switch whenever you like.

  • [[page]] #tag ((ref))Links, tags and block references
  • TODO DOING NOW LATER DONETask markers, priorities, SCHEDULED and DEADLINE
  • {{query …}}Simple and advanced queries, live in the page
  • key:: valuePage and block properties, journals folder, assets
  • config.ednGraph settings, plus your logseq/custom.css
AI with Pando · optional

An assistant that asks before it writes.

Connect Pando — managed by Bitácora or your own server — and your graph gains meaning-based search and an agent. In the app, amber always marks text the machine wrote and you have not accepted yet.

About Pando

Semantic and hybrid search

Keyword hits first, then blocks that match by meaning. Snippets always come from your local files.

Chat with approved edits

Streaming answers and tool cards. Each proposed change is a diff with Apply and Deny, undoable and logged.

Ghost text

Pause at the end of a block and a faint continuation appears. Tab to accept, any other key to dismiss.

Compose with AI

Ctrl/⌘J under any block. Review the draft, then insert, replace, retry or discard.

Journal review

Summarise today or this week: themes, mood, tasks still open and next actions. On demand.

Recommendations

Related pages, links and tags for the page you are on — checked against your real blocks.

Your notes stay yours.

  • Every AI feature is off until you opt in
  • Consent per graph, with page exclusions
  • private:: content is never sent
  • Activity log and tokens in the system keychain
  • One action to revoke and remove your data
  • Editing never needs the network
For agents and scripts

An MCP server is always on deck.

Bitácora runs a Model Context Protocol endpoint on localhost, protected by a token, so the AI agents you already use can search and edit your notes. semantic_search and related_blocks are there too. The same powers come in a command-line tool.

# check the index and Pando connection
bitacora-cli doctor --graph ~/logbook
bitacora-cli semantic status --graph ~/logbook

# search by meaning
bitacora-cli semantic search "harbour charter" --limit 10
