## Description
Owner feedback after installing 2.0.2 (2026-10-08), nine items:
1. Journals feed: an empty today cannot get a first block / indent from the feed.
2. Tasks view: tasks disappear after editing scheduled dates until restart.
3. Footer shows the running version.
4. Settings reachable from a gear icon (full menu + settings sections), not only the Pando top menu.
5. Git over HTTPS prompts for credentials and stores them in the system keychain.
6. Git over SSH lets the user pick the private key when system keys do not work.
7. Today's journal shows tasks scheduled today, tomorrow, and DOING below its blocks.
8. Agent panel folds tool calls and approvals into a collapsed block.
9. Settings let the user enable Pando models for an agent model selector.

## Acceptance Criteria
- One story per item, each done or in_review with evidence.
