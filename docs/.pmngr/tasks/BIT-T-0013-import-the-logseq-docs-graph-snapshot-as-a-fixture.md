## Description
1. **License check first.** Before copying anything, determine the license of the Logseq documentation graph (`github.com/logseq/docs`, a tagged commit contemporary with Logseq 0.10.15) and whether it allows redistribution inside an MIT repo. Record the finding (license name, file/URL, commit SHA) in the PR. Do not copy any file until this is confirmed.
2. **If redistribution is allowed:** copy it into `fixtures/graphs/logseq-docs/` keeping `pages/`, `journals/`, `logseq/config.edn` and a pruned `assets/` (drop large binaries; keep a few small images so asset links resolve), and add the upstream LICENSE file next to it. Write `fixtures/graphs/logseq-docs/PROVENANCE.md` with: source repo URL, commit SHA, date, license, list of pruned paths, and the size of the snapshot.
3. **Fallback (license missing, unclear or incompatible):** do not import it; instead generate our own realistic fixture graph `fixtures/graphs/realistic/` (> 100 pages, namespaces, journals, properties, queries, embeds, assets) authored or generated by Bitacora tooling, with a `PROVENANCE.md` stating it is self-authored, and record the decision.

## Acceptance Criteria
- License decision recorded before any import.
- Snapshot (or fallback graph) is < 10 MB and contains > 100 pages.
- `PROVENANCE.md` (and upstream license, if imported) are present.
- If imported: no file was modified compared to upstream (verify with `diff -r` against a fresh clone at the recorded SHA, excluding pruned paths).
