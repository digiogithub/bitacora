## Description
Create `packaging/flatpak/es.digio.Bitacora.yml` (runtime `org.freedesktop.Platform` current version + `rust-stable` SDK extension), `cargo-sources.json` generated by `flatpak-cargo-generator.py` from `Cargo.lock` (regenerated by `cargo xtask flatpak-sources`), `finish-args`: `--socket=wayland`, `--socket=fallback-x11`, `--device=dri`, `--share=network` (git remotes + MCP), `--share=ipc`, `--talk-name=org.freedesktop.secrets` (keyring), `--socket=ssh-auth`; include `git` (module or `org.freedesktop.Sdk.Extension`-provided) for ADR-007. Reuse the `.desktop` and metainfo from the bundles story. CI job `flatpak` on tags using `flatpak/flatpak-github-actions/flatpak-builder`, uploading the `.flatpak` bundle to the draft release.

## Acceptance Criteria
- `flatpak-builder --sandbox` succeeds offline; app launches on GNOME Wayland and KDE X11 test VMs.
- `appstream-util validate` / `flatpak-builder-lint` pass.
