Done; findings in docs/design/pando-integration.md 5.4. KB lives in `<Data.Directory>/pando.db` (default relative `.pando`, so per-cwd); IPC primary election is per cwd. Experiment on real Pando v1.2.11 (manual script, not automated): two `pando serve` in different dirs with a global `[Data] Directory = <abs>`: a doc upserted by A (`file_path=bitacora/test/page.md`) was found by B with `path_prefix=bitacora/`. Decision: never set [Data]/[Remembrances]; the KB is shared exactly when the user's global config has an absolute Data.Directory, otherwise the instance has a private DB under the cache dir. Settings page should surface which applies.
