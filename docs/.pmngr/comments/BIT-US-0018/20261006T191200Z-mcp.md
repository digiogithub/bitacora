BIT-T-0123 follow-up (commit 627eec5): the MCP `query` tool now routes DSL strings to IndexReader::query_simple and #+BEGIN_QUERY / EDN maps / bare [:find vectors to query_advanced. QueryContext is built from the server clock (local today, now_ms) plus the optional current_page/current_block args. `unsupported: <construct>` maps to a NOT_SUPPORTED error, ignored constructs are returned as `warnings`, and results are paginated (limit/cursor, kind blocks|pages|rows). Note: the "Datalog input -> INVALID_QUERY" criterion is superseded (datalog subset is now executed; malformed text still gives INVALID_QUERY). HTTP tests: crates/bitacora-mcp/tests/read_tools.rs::query_tool_routes_simple_and_advanced_queries.
