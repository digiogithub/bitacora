Merged. Root cause: releases ship only `bitacora`; askpass looked for a separate `bitacora-askpass` binary, so GIT_ASKPASS was empty with GIT_TERMINAL_PROMPT=0 and git failed silently. Fix: `bitacora` is multi-call (`BITACORA_ASKPASS_MODE=1` → `askpass::run_if_askpass_mode()` before any init). HTTPS auth hint, Settings → Sync "Forget saved credentials" (`ChainProvider::forget_remote`). Keychain only. Tests incl. `tests/askpass_helper.rs`. Pending: real HTTPS remote in a packaged build on 3 OS (Windows GUI-subsystem stdout to git).
