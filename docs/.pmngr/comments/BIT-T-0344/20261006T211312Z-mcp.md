Editor sets set_editing_block(Some(id)) on enter and None on exit by BlockId (editing.rs index-based hook stays for read-only views). EditingBlockChanged now reaches the UI as SessionEvent::EditingConflict; OutlineEditor::on_editing_conflict rebases its buffer on the disk text and shows a Keep mine / Take disk bar; resolve_conflict(keep_mine) writes the buffer over the disk text on the next flush or reloads the disk text. If the edited block disappears in an external reload the unsaved text is put on the clipboard.
