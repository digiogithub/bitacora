Done in commit 9377627. editor/external.rs apply_external (thin adapter over bitacora_merge::match_pages/merge_page, no second algorithm), used by the watcher path (Request::ExternalChange) and the pre-write check in flush. Merge result is applied as page bytes (aligned ids, page stays dirty, written normally, history untouched) rather than a Vec<Op>. Tests: crates/bitacora-core/tests/external_changes.rs, crates/bitacora-runtime/tests/external.rs. Note: blocks under 4 tokens only match exactly (bitacora-merge rule), so same-block edits of tiny blocks keep both versions instead of conflicting.
