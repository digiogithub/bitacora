## Description
Settings are only reachable from the Pando top menu. Add the usual gear icon in the title bar that opens the full app menu and gives access to every settings section (general, appearance, sync, Pando, agent...).

## Acceptance Criteria
- Gear icon visible in the title bar on all OS.
- Menu lists the app menu entries and a Settings entry opening the settings view with all sections.
- Keyboard shortcut (Ctrl/Cmd+,) opens settings.
