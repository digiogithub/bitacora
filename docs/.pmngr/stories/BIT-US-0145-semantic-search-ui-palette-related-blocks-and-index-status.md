## Description
As a user, I want to use semantic search from the palette, see related blocks for what I'm reading, and know the state of the semantic index.

## Acceptance Criteria
- Palette hybrid mode toggle (default on when available) with "semantic unavailable" chip.
- "Related blocks" section in the right panel Context tab for the current block/page, click navigates.
- Settings show per-graph status (synced, pending, last error) with Resync and Purge actions.
