## Description
Chat auto-approves Pando permission prompts for allow-listed read tools (MCP_READ_TOOLS, KB_READ_TOOLS); write prompts get a "Remember my decision" option persisted machine-local per graph; revoking consent clears them; Settings > Pando lists and forgets them. Unknown tools always ask.
