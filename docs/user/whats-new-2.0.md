# What is new in Bitacora 2.0

- **New design.** One colour system with Bitacora Light and Bitacora Dark, new typography, restyled outline, journals, palette, popovers and settings. See [[ui-tour]].
- **Frameless window.** Bitacora draws its own 52 px top bar with the window controls, tabs and actions. See [[ui-tour]].
- **Reopens your last graph** at startup, plus a **Graph menu** (Open graph, Open recent, Close graph). See [[ui-tour]].
- **Tasks view.** All open tasks grouped Overdue / This week / Later / No date, with filters. See [[ui-tour]].
- **Right panel** with Context (local graph, page properties, backlinks, related blocks, opened blocks) and Agent tabs. See [[ui-tour]].
- **Graph view** with settings saved in `config.edn`, focus and export to SVG and PNG. See [[graph-view-guide]].
- **Optional Pando integration** (managed or external) for semantic search and an AI assistant, with per-graph consent, exclusions and an activity log. See [[pando-setup]].
- **AI features** (all opt-in): semantic and hybrid search, chat with approved edits, journal review, recommendations, inline ghost text and Compose with AI. See [[ai-features]].
- **Semantic tools for agents and scripts:** MCP `semantic_search` and `related_blocks`, and `bitacora-cli semantic ...`.
- **Settings migration** from 1.x is automatic. See [[upgrade-from-1x]].

Not in 2.0: custom colour-scheme files (planned right after 2.0) and user theme JSON files; `logseq/custom.css` keeps working.
