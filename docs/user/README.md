# Bitacora user guide

Bitacora is a desktop outliner for Logseq Markdown graphs. This guide covers what you use day to day. For internals see [[architecture]].

Your notes stay plain Logseq Markdown files in your graph folder. Bitacora never needs the network to edit them; every AI feature is optional and off until you set it up.
