# Sync UI: BIT-US-0043/0046/0047/0048/0054/0070 (+ BIT-T-0344 hook)

Part of [[bitacora-full-development-plan]]; builds on [[changes/bit-us-0078-0079-0080-palette-sidebars-runtime.md]], [[changes/bit-us-0047-0048-sync-status-recovery-history.md]], [[changes/bit-us-0052-0053-file-merge-policies-and-conflict-state.md]], [[changes/bit-us-0046-askpass-credentials-git2-push.md]], [[changes/bit-us-0041-0043-git-backends-and-onboarding.md]], [[changes/bit-us-0068-0069-0070-external-reload-merge-conflict.md]]. ## What changed
- Runtime (additive): `SyncOptions::{cli, credentials}`; `build_engine` uses them (hybrid/gix backends get the provider).
- `session.rs`: `SessionHandle::run` (closures on the session thread), `SyncSetup` (branch, device, cli, credentials, timing prefs -> `SyncOptions.tune`), events `Sync(SyncStatusView)`, `DiskConflict(ConflictNotice)`, `DiskConflictCleared`, notices SyncUnavailable/SyncRecovery/EditingBlockChanged; sync failure at open retries without sync; Drop sends `Stop` (handles keep the channel open).
- `sync_prefs.rs` (per-graph `sync.json`, form validation, clamps idle 5-600 etc., actionable errors), `credentials.rs` (`CredentialHub`: ChainProvider + AskpassServer + CliConfig, `PromptRequest`), `editing.rs` (T-0344 hook).
- Views: `sync_dialog` (enable / clone / migrate separate gitdir, background git), `credential_dialog`, `sync_panel` (status, backend, install-git hint, prefs, CLI doc), `status_bar` (SyncStatusView, Sync now/Retry), `history`, `conflicts` (cards, word diff, Mine/Theirs/Both/Edit, bulk, keys), `disk_conflict` (banner + diff, also the page-level sync-conflict strip), `modal`; `PageView` focus + conflict block markers; palette commands (Sync now, Sync settings, Page history, Resolve conflicts, Open graph from a remote); picker button.
